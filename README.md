## Selected projects

Apps

- [financial_planner](https://github.com/du0ks/financial_planner): Prosperity, a budgeting PWA for accounts, cards, multiple currencies and gold. Plain JavaScript, works offline, syncs per user through Supabase.
- [Leo](https://github.com/du0ks/Leo): block-based note-taking app with notebooks. React, TypeScript and Firebase, as a web PWA and a Tauri desktop app.
- [311](https://github.com/du0ks/311): team project for a database course. A 12-table PostgreSQL schema for an electronics retailer and a vanilla JavaScript admin panel for sales, orders and after-sales service.

Automation and tools

- [inovapulse](https://github.com/du0ks/inovapulse): builds İnovakademi's weekly foreign-trade bulletin. A scheduled Python pipeline collects freight rates, trade figures, events and news, summarises them with an LLM and publishes a draft to a web panel with PDF export.
- [apollo-lead-finder](https://github.com/du0ks/apollo-lead-finder): Python CLI that finds companies and contacts through the Apollo API, scores and ranks them, and exports Excel previews. It asks for confirmation before any step that spends credits.
- [council-agent](https://github.com/du0ks/council-agent): FastAPI app where several Gemini agents discuss a goal in two rounds and a moderator turns it into a 7-day plan.

Data analysis

- [customer-churn-analysis](https://github.com/du0ks/customer-churn-analysis): telco churn study with PCA, factor analysis, MANOVA, canonical correlation, clustering and classification in R and Python.
- [real-estate](https://github.com/du0ks/real-estate): rental listings collected from sahibinden.com for Mecidiyeköy, İstanbul, and a multiple linear regression on what drives the rent.
- [airbnb](https://github.com/du0ks/airbnb): R Shiny app for comparing Airbnb listings in nine European cities, with a Leaflet map and regression-based price estimates.
